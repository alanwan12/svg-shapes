# SVG Shapes

Three small HTML files that each draw one SVG shape. They are basic practice pages for SVG markup.

| File | Shape |
| --- | --- |
| `svg-circle.html` | red circle with a black outline |
| `svg-rectangle.html` | blue rectangle with a black outline |
| `svg-myshape.html` | lime polygon with a purple outline, drawn from four points whose edges cross |

## Run it
Open any of the HTML files in a browser.
